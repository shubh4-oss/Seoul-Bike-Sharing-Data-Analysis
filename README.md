# Seoul Bike Sharing Demand Analysis

## 1. Project Overview

This project analyses the Seoul Bike Sharing Demand dataset to understand the factors influencing hourly bicycle rental demand.

The project uses Python, SQL, Exploratory Data Analysis (EDA), Data Visualisation and Multiple Linear Regression.

## 2. Business Problem

A bike-sharing company needs to understand how weather conditions, time of day, seasons and holidays influence bicycle rental demand.

The objective is to analyse historical rental data and develop regression models to forecast hourly demand.

## 3. Dataset Information

- Dataset: Seoul Bike Sharing Demand
- Original observations: 8,760
- Original columns: 14
- Target variable: Rented Bike Count

## 4. Tools and Technologies

- Python

- Seaborn
- Scikit-learn
- SQL
- Google Colab

## 5. Project Workflow

1. Data cleaning and preprocessing
2. Descriptive statistical analysis
3. Exploratory Data Analysis
4. Data visualisation
5. Multiple Linear Regression without interaction
6. Multiple Linear Regression with interaction
7. Model comparison
8. SQL-based business analysis

## 6. Key Business Questions

- Which hours have the highest bicycle rental demand?
- How does temperature influence rentals?
- Does demand differ across seasons?
- How do holidays affect rental demand?
- Can regression models help forecast hourly demand?

## 7. Expected Business Benefits

The analysis can help bike-sharing operators improve bicycle allocation, plan operational resources and understand periods of high and low demand.
